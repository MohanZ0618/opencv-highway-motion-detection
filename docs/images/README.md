# Example media

These images illustrate the project's local experiments. The synthetic scene
was created in PowerPoint for a controlled motion test. Highway images and
their processed masks were captured from third-party traffic footage used
in the project.

The original highway footage URL and media license were not preserved in the
project materials. No ownership or license to that underlying footage is
claimed here. The repository's MIT software license does not grant rights
to third-party footage or its derived images. Full input and output videos
are not redistributed in this repository.
